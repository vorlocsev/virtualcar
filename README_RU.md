# Virtual Car: исследования и эмуляция Volvo P2

**Статус: dev26, экспериментальная разработка.** Сейчас проект содержит 32-битную трассирующую DLL J2534, Windows GUI OneClick, классификаторы запросов CEM и пассивный наблюдатель LS-CAN. Это **не полноценный эмулятор автомобиля** и **не оригинальная DLL** `VirtualCarJ2534.dll`.

## Состав исходников

- `proxy/` — C99, прокси J2534, маршрут CEM, состояние XC90 MY2009.
- `cmd/oneclick/` — Windows x86 графический инструмент для диагностики.
- `cmd/trace_summary/`, `cmd/ignition_report/`, `trace_attribution/` — анализаторы Go.
- `research/dev23/`, `research/dev24/`, `research/dev25/` — снимки ранее разработанных модулей.
- `tests/` и `.github/workflows/ci.yml` — проверки и CI.

## Как собрать

На Linux с установленными `clang`, `lld-link`, `gcc`, Go 1.23+ и `file`:

```bash
bash build_dev26.sh
```

Скрипт компилирует DLL, анализаторы и Windows x86 GUI, затем запускает тесты. До первой сборки `go test ./...` может не работать, так как используемые `go:embed` файлы создаёт скрипт.

## Важные ограничения

- Оригинальные исходники `virtualcar.c` / `VirtualCarJ2534.dll` версии 0.3.6.6 не обнаружены и **не включены**.
- Достоверные ответы CEM на A3/B9F0 отсутствуют; они не генерируются.
- Рабочие ответы B9FB остаются на стороне исходной DLL.
- Файлы стороннего диагностического ПО, реальные VIN, CAN-дампы, ключи/секреты и персональные данные не включены.
- Отдельный проект от Dvinholm.

Для дальнейших этапов см. `docs/ROADMAP.md`, историю и ограничения `docs/PROVENANCE.md`.
