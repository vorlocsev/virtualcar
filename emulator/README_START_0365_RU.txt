SectorV Virtual Car 0.3.6.5. Windows x86, только чтение.

1. Распакуйте в НОВУЮ папку. Закройте SectorV и VDASH.
2. Запустите VirtualCarControl.exe от администратора.
3. Нажмите «1. Подготовить XC90 V8 2005».
4. «2. Начать тест», затем откройте SectorV (или VDASH).
5. «3. Показать результат»; для полной диагностики приложите
   %TEMP%\SectorVVirtualCar.log

BASE: идентификаторы F1B0/F1A3 не настроены.
CEM-HWID-AB: исследовательские значения из Flash, но соответствие
этим UDS DID не подтверждено. Данные НЕ являются проверенным
оригинальным ответом номера CEM!

Не смешивайте папки BASE и CEM-HWID-AB.
Не публикуйте личный архив с VIN.
Подробнее: README_0365_CEM_ID_ECU_RU.md
