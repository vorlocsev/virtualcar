# B3A19: наблюдение 29-битных UDS-маршрутов VIDA, без RX ECU

Источник: результат B3A18 от оператора, 284 J2534 TX, 206 UDS без
совпадения с настроенными адресами, 78 Volvo D2, ответы ECU не доказаны.

Изменения:
- `src/p2core/vida_uds29_route.h`: узкая C99-проверка точного 29-битного
  адреса `18DA<target>F1`, протокола J2534 ISO15765, длины payload = 3
  и SID `22` либо `19`. SID 22 использует DID, SID 19 свои операнды.
- `src/virtualcar.c`: только после текущих сконфигурированных маршрутов
  и исключения CEM F114 наблюдаемый запрос маркируется
  `ECU_OTHER/missing_profile/no_response`. Различаются неустановленный
  адрес и другие неподдерживаемые запросы. Новый ответ не создаётся.
- Тесты компилируют C-классификатор без Windows и проверяют границы, а
  также расположение нового обработчика после существующих маршрутов.

Сохраняется принцип fail-closed: не объявлять ECU обнаруженным по запросу
VIDA, не выводить CAN reply ID из адреса запроса, не подставлять VIN,
не включать фиктивный B9FB/B9F0/F114/keyword и не считать этот шаг
подтверждением автоматического VIDA ReadVIN.

Оригинальный приватный INI, VIN владельца, OEM-журналы и payload не
загружаются в репозиторий и не изменяются. Это только код для Draft PR;
оригинальная VIDA и Windows x86 DLL не тестировались после изменения.
