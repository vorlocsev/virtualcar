# SectorV OneClick dev26: CEM Vehicle Core подключён к реальным вызовам J2534

## Результат

Рабочая тестовая **трассирующая** DLL `VirtualCarTrace32.dll` теперь вызывает код `p2_j2534_bridge.c` и объединённое ядро dev25 (`p2_vehicle_core.c`, `p2_cem_router.c`, `p2_ls_observer.c`). Это самостоятельный 32-битный J2534-прокси, который загружает ВАШУ оригинальную `VirtualCarJ2534.dll`, пересылает ей все J2534 вызовы без модификации и собирает только метаданные. **Это не исправленная оригинальная виртуальная DLL.**

## Использование в VMware (Windows x86)

1. Распакуйте архив `SectorV-OneClick-dev26-J2534-Vehicle-Core-Windows-x86.zip` в отдельную папку.
2. Запустите `SectorV-Trace-OneClick-v0.3.6.7-dev26.exe` от обычного пользователя. В программе выберите установленный `SectorV.exe` и оригинальную `VirtualCarJ2534.dll` v0.3.6.6 (если они не обнаружились автоматически).
3. Нажмите большую кнопку запуска. При первой регистрации `VirtualCar Trace VM dev26` потребуется UAC; создаётся отдельная запись J2534 в 32-битной ветке реестра. Другая J2534 регистрация не перезаписывается.
4. В запущенном SectorV выберите **VirtualCar Trace VM dev26**, выполните исключительно чтение VIN / CEM / ECU и закройте SectorV.
5. Пришлите `j2534-diagnostics.json` из `Desktop\\VirtualCar-Trace-Results`. При необходимости также журнал `j2534-trace-*.jsonl` из `%LOCALAPPDATA%\\VirtualCar-Trace-OneClick\\dev26\\logs`.

## Технические изменения

- Реальные успешные `PassThruConnect` записывают `ChannelID`, протокол, скорость и новое поколение канала. Успешный `PassThruDisconnect` удаляет карту канала. События неизвестных или устаревших каналов не связываются с произвольной скоростью.
- `PassThruWriteMsgs`: только после успешного возвращения оригинального драйвера наблюдаются принятые сообщения и классифицируются D2 A3/B9E0/B9F0/B9FB/B9FC/A6-кандидат.
- `PassThruReadMsgs`: подготовлена наблюдательная обработка сырых LS-CAN кадров. Сигналы сообщества `olegel/VolvoCan` **выключены по умолчанию**, так как их идентификаторы для целевого XC90 V8 2009 не подтверждены. Никаких байтов данных/положения ключа прокси не записывает.
- Журнал сохраняет прежнюю совместимую `schema=15`; на событиях добавлено поле `core_version:26`, а для узнанных D2-запросов `core_class` и `core_decision` (0 = существующий обработчик, 1 = пометка маршрута, 2 = нужно подтверждение ответа). Это аннотации, не J2534 status.
- Итоговый отчёт содержит `assessment.j2534_vehicle_core` и строку об обнаруженных D2-операциях в UI.
- Объект ядра и карта каналов защищены Win32 `CRITICAL_SECTION`. DLL не требует MSVCRT: импортирует только KERNEL32.dll.
- НЕ создаются искусственные E3, F9F0, ответы B9FB, зажигание ON, PIN, иммобилайзер или загрузка ПО ECU.

## Важные пределы

- Успешная отправка TX не подтверждает получение ответа от ECU; счётчик B9FB обозначает делегирование существующей DLL, не успешное чтение VIN.
- Пассивный CEM сигнал `0x00617FF8` из VolvoCan не приравнен к диагностическому CEM Reference 6660.
- Существующая версия SectorV по-прежнему может показывать «CEM не подтвердил подготовку обычного режима»: этот пакет исследует, но не устраняет отсутствие ответов A3.
- Пользовательские Windows/VMware испытания этой конкретной сборки ещё НЕ проведены. Сборка и CI-аналоги выполнялись в Linux-кросс-среде.
- Полноценное исправление оригинального эмулятора требует исходников `virtualcar.c`/проекта рабочей `VirtualCarJ2534.dll`, которых в текущих исходных файлах нет.

## Сборка из SOURCE

`build_dev26.sh` использует Clang/LLD для Windows x86, Go для GUI и анализаторов, GCC/Clang и Go для тестов. В `tests/test_bridge.c` 11 групп проверок: маршрутизация, смена ChannelID, D2 A3/F0/FB, неизвестные каналы, неверные длины, неизменность зажигания, отключенный пассивный декодер, повторная инициализация и переполнение таблицы.

Отдельная статическая проверка `objdump -p` подтвердила 14 J2534 экспортов и единственную зависимость DLL от KERNEL32.dll. 24 регрессионные C-проверки классификатора, Go tests / Go race / Go vet и ASan/UBSan прошли. Это не доказательство функциональной совместимости с реальным SectorV в Windows.
