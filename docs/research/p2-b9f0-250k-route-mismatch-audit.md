# P2 B9F0: проверка 250 кбит/с и соседнего 0x40 B9F0

Статус: **только локальный read-only аудит нативного логгера**.
Не является записью ответа физического CEM, подтверждением VIN / Hardware
или идентификации ECU оригинальным SectorV/VIDA.

## Полученные владельцем наблюдения

На полном `SectorVVirtualCar.log` анализатор B3A318 зарегистрировал
805 295 строк, 8 765 D2-событий, 126 текстовых групп логгера,
1 727 запросов `B9 F0`. Из них для `0x50 / 250000` — **28** запросов
в 26 группах (25 по одному, одна — три).

При просмотре следующих 20 строк после каждого запроса:
- 28 раз обнаружен `strict route rejected` с точным эхо `CB 50 B9 F0`;
- 28 раз рядом обнаружен `no validated response fixture` с **другим**
  эхо — `CB 40 B9 F0`.

Исходное окно строк не устанавливает, что второй исход относится
к запросу `0x50`. Числа в группах логгера не удостоверяют транзакции.
Формального сопоставления каждого исхода с отдельным запросом ещё
нет; оно выполняется следующим локальным аудитом.

## Сверка с кодом эмулятора

В `emulator/src/virtualcar.c` загрузчик **базовых** D2-фикстур
инициализирует `d->baud` как `125000` при `target=0x40`
и `500000` при `target=0x50`.
В `process_d2` при `StrictRouting` и несовпадении
`c->baud != d->baud` запрос заканчивается `strict route rejected`;
при совпадающем маршруте, но `frame_count=0` — `no validated response fixture`.
Для этих 28 наблюдений причины различны: `0x50` — строгий маршрут,
`0x40` — недостающий валидированный блок.

Указанные скорости — **допущение лабораторного эмулятора**.
В оригинальном VIDA CarCom каталоге для кандидата CEM
`31296075 AA` скорость `busRate` отсутствует. Запрос 250 кбит/с
сам по себе не доказывает правильность или ошибочность OEM-маршрута.

## Полный read-only аудит с сохранением расстояния в строках

`audit_vida_b3a50_d2_matrix.py` теперь поддерживает CLI `--native`,
читает до 256 МиБ / 6 млн строк, считает до 150 000 D2-событий.
Для связывания `request → outcome` он требует точные адрес и команду,
тот же текстовый префикс логгера, ровно один кандидат в пределах
24 **неотфильтрованных исходных** строк. Неоднозначные пары не засчитываются.

```powershell
& (Get-Content 'E:\VirtualCar\Tools\python312.path' -Raw).Trim() 'C:\Users\vorloc\Projects\VirtualCar-VIDA-D2\emulator\tools\audit_vida_b3a50_d2_matrix.py' --native (Join-Path $env:TEMP 'SectorVVirtualCar.log')
```

В отчёте сравнивать `paired_route_outcomes`,
`unpaired_requests`, `unpaired_outcomes`,
`ambiguous_pairings`, `complete_source_scan`.
Атрибуция по строкам нативного логгера не подтверждает
клиентское принятие VIN или реальный ответ ECU.

**Не менять** `StrictRouting`, фиксированные маршруты, оригинальную
VIDA, ответы J2534 или ECU-фикстуры без независимого доказательства.
