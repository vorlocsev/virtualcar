The match \`0c00c8af80205920\` is a **unique global profile** in this owner database, not a model-specific XC90 profile.

This definitively closes the *catalog/profile matching* gap: the original VIN script \`0900c8af8184c004\` has a direct profile map to the one global FolderLevel=0 profile, so the function includes that map even when VIDA passes its non-null special \`VehicleProfile.Empty\` carrying \`EMPTYPROFILE\`.
