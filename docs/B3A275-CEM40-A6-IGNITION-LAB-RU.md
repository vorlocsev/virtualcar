# B3A275 — отдельный синтетический ответ CEM40 A6 1A04 (VIDA experiment)

**Статус:** исходный код и host C regression подготовлены для изолированного исследования.
Оригинальная VIDA, x86 DLL и физический CEM **не проверены** на этой ветке.

## Основание

В сохранённом оригинальном сеансе VIDA (`IEXPLORE.EXE`, лабораторный PID
`00003610`, J2534 CAN_PS `0x8004`, 125000 бит/с) дважды передан:

```text
TX 000FFFFE CD 40 A6 1A 04 01 00 00
```

Исследованный образец положительного ответа из сторонних наблюдений:

```text
RX 00800003 CD 40 E6 1A 04 1E 00 00
```

Это **не** измеренное состояние зажигания нашего XC90 V8 MY2009.
Числа `18`, `1C`, `1D`, `1E` допускаются только как явные лабораторные
состояния по опубликованным наблюдениям. CEM OEM-совместимость не подтверждена.

## Настройка (только в новой лабораторной копии)

В отдельном `virtualcar.ini` добавляются:

```ini
[Diagnostics]
EnableVidaCanPsLab=1
EnableCem40A6IgnitionLab=1

[CEM40_A6_1A04]
Enabled=1
Frame=CD 40 E6 1A 04 1E 00 00
```

Если раздел `[Diagnostics]` уже существует, добавляются только новые ключи,
без повторного заголовка. Нельзя переносить этот пример в уже
зарегистрированную базовую D2 Replay Lab или в оригинальные конфигурации VIDA.

Обязательны оба флага `EnableCem40A6IgnitionLab=1` и
`[CEM40_A6_1A04] Enabled=1` вместе с полным корректным восьмибайтовым
`Frame`. Пропуск, ошибка, неподдерживаемое состояние или другая структура
отключают обработчик (без ответа). Нет значения зажигания по умолчанию.

Ответ возможен только при одновременном выполнении:

- J2534 wire protocol `CAN_PS=0x8004`, исходный протокол CAN;
- скорость 125000, реальные виртуальные pins 3/11 (`J2534_PINS=0x030B`);
- 29-битная адресация на канале **и** ровно `CAN_29BIT_ID` в `TxFlags` самого сообщения;
- CAN TX ID `000FFFFE`, полные 8 байт точного запроса
  `CD 40 A6 1A 04 01 00 00`;
- успешно установленный PASS CAN-фильтр при `StrictJ2534Filters=1`,
  иначе RX подавляется штатным фильтром;
- отклик `00800003`, payload — строго указанный `Frame`.

При опции `0` поведение старой лаборатории неизменно: все CEM A3/A6 остаются
без ответа. Другие адреса, A3, A6 D0 D1, B9 F5/F8, AE 1B не имитируются.
Обработка `B9 F0/FB/FC` и текущих GGD DID не меняется.

## Проверки / границы результатов

В `emulator/tests/virtualcar_test.c` добавлена host C серия из девяти
проверок: disabled, pin gate, точный TX/RX с J2534 метаданными, допустимое
значение, отказ невалидного кадра, другие A3/A6, изменённый payload/ID/TxFlags,
обычный CAN и отказ RX-фильтра. Существующие regression остаются.

Исходный код нуждается в x86 сборке и запуске host/native тестов на
точном HEAD. CI, оригинальная VIDA ReadVin, T111, T122, полный ECU-ID
и реальный J2534 не подтверждены. Не интерпретировать синтетическую
реакцию как OEM-read или доказательство перехода к следующей стадии VIDA.

План A/B: новая x86 DLL с отдельным INI и **новой** записью J2534 без
перезаписи D2 Replay Lab; полный новый VIDA-сеанс с `Active INI`, фиксацией
точного `A6 1A04` TX, `E6 1A04` RX, результатом UI `READ VEHICLE`;
сравнить с уже зафиксированной исходной D2 Replay Lab. Не менять данные
ECU или VIDA, не запускать программирование.
