# Подключение p2_cem_router к существующему virtualcar.c

## Почему это не готовый патч исходного virtualcar.c

Исходник работающей VirtualCarJ2534.dll 0.3.6.6 не входит в полученные архивы. Модуль предназначен для интеграции в этом проекте после получения его точной версии; он НЕ заменяет существующий драйвер и НЕ представляет новую работоспособную DLL.

## Точка подключения

В коде `PassThruWriteMsgs` **после проверки длины PASSTHRU_MSG**, но до существующей логики маршрутизации, можно добавить пассивное наблюдение:

```c
#include "p2_cem_router.h"

/* Пример, имена ctx и can_bitrate нужно адаптировать под исходный проект. */
static void inspect_j2534_tx(const PASSTHRU_MSG *m, uint32_t can_bitrate) {
    uint32_t can_id;
    p2_cem_result res;
    if (!m || m->DataSize < 4 || m->DataSize > sizeof(m->Data)) return;
    can_id = ((uint32_t)m->Data[0] << 24) |
             ((uint32_t)m->Data[1] << 16) |
             ((uint32_t)m->Data[2] <<  8) |
             ((uint32_t)m->Data[3]);
    res = p2_cem_classify(can_id, can_bitrate, m->Data + 4,
                          m->DataSize - 4);
    /* Допустимо регистрировать только res.request, route и decision.
       Нельзя логировать CAN payload, VIN, PIN и токены. */
    (void)res;
}
```

**Нельзя** использовать `res.decision` как новый J2534 return status: это внутренняя классификация, не код ошибки SAE J2534. `PassThruWriteMsgs` должен продолжить выполнение обычного обработчика без изменения параметров и статуса.

- `B9FB`: оставляем старую очередь 13 кадров, ничего не подменяем.
- `A3`: показываем запрос и необходимость подтверждённой трассы, не возвращаем `E3 02`.
- `B9E0`, `B9F0`: пока только классифицируем. Реальные ответы отсутствуют.
- `A6` Reference 6660: пометка **candidate**; отсутствие чтения нельзя приравнивать к Ignition OFF.
- Маршруты: 0x50/500000 и 0x40/125000 соответствуют текущему целевому профилю XC90 V8 MY2009. На других годах/скоростях потребуется параметризация.

## Как подключить в Windows x86

Положите `src/p2_cem_router.c` и `src/p2_cem_router.h` в рабочий проект и добавьте C-файл в сборку. Либо скомпонуйте `build/p2_cem_router_x86.obj` / `build/p2_cem_router_x86.lib` (COFF/i386), если используете совместимый MSVC link.exe. Исходная DLL пока не пересобиралась.

В архиве нет реальных CAN-ответов. Тестовые значения `12345678` и другие синтетические данные из `tests/` не относятся к автомобилю.
