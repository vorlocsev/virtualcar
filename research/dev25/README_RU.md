# Virtual Car dev25: объединённое CEM D2 / LS-CAN ядро

**Статус:** исходники C99 и Windows x86 COFF статическая библиотека для подключения к существующей VirtualCarJ2534.dll. Это **не новая J2534 DLL**; секторную диагностику в VMware эта сборка не меняет.

## Состав

- `src/p2_cem_router.*`: классификация диагностических запросов CEM A3, B9E0, B9F0, B9FB, B9FC, возможный A6 Reference 6660; валидация B9F0 по двум независимым форматам.
- `src/p2_ls_observer.*`: пассивный декодер LS-CAN (CEM, TCM, CCM, REM, SWM), основанный на описании VolvoCan; без CAN TX.
- `src/p2_vehicle_core.*`: единый контекст автомобиля, настройки HS/LS, отделение диагностического состояния зажигания от широковещательного сигнала ключа, проверка J2534 Data, защита от устаревших событий.
- `build/p2_vehicle_core_x86.lib`: Windows x86 COFF статическая библиотека из трёх модулей; `*.obj` можно использовать отдельно.
- `tests/test_vehicle.c`: 8 интеграционных групп, синтетические тестовые данные без настоящего VIN и секретов.
- `docs/INTEGRATION_RU.md`: конкретные шаги подключения к `PassThruWriteMsgs` и `PassThruReadMsgs`.

## Результат

| Сценарий | Итог |
|---|---|
| A3 `CF 50 A3 02 03 A5 A5 00` | классифицируется, **0 синтезированных RX** |
| B9F0 | классифицируется, **0 синтезированных RX** |
| B9FB | `KEEP_EXISTING`, текущий обработчик DLL не меняется |
| D2 ref 6660 | кандидат, диагностическое зажигание `UNKNOWN` |
| LS CEM `0x00617FF8` | отключено по умолчанию; только после ручного подтверждения ID |
| J2534 RAW CAN | 4-байтовый big-endian CAN ID распознаётся из `Data[0..3]` |
| Ошибка скорости/маршрута | диагностическая аннотация, не блокирует J2534 |

## Проверки

```
sh tests/run_tests.sh
```

GCC, Clang, Clang ASan/UBSan: по 8 из 8 групп тестов. Windows x86: компиляция C99 в COFF объектный файл и библиотеку; исполнение в VMware ещё не проверено.

Источники: [VolvoCan](https://github.com/olegel/VolvoCan), собственные отчёты J2534 dev18–22, ранее полученные результаты IL-анализа SectorV. Реальных ответов CEM A3/F0 в опубликованных файлах нет.
